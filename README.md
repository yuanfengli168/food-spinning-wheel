# 🍽️ Food Spinning Wheel

Can't decide what to eat? Let the wheel decide!

## Features
- 12 preset foods: Pizza, Sushi, Burger, Tacos, Ramen, Salad, Curry, Pasta, Sandwich, Fried Chicken, Stir Fry, Burrito
- Canvas 2D rendering with smooth cubic ease-out animation
- Live checkbox sync — toggle foods and the wheel redraws instantly
- Spin button disabled when fewer than 2 foods are selected
- Zero dependencies — single `index.html` file
